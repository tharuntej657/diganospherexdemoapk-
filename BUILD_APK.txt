DiagnoSphereX - standalone Android app (the app files are packed INSIDE the APK; no website, works offline)

OPTION A - no installs, free, using GitHub (easiest)
 1. Create a free account at github.com and make a new repository (e.g. diagnospherex).
 2. Upload ALL files from this folder, including the hidden .github folder
    (on a laptop: drag the whole folder contents into "Add file > Upload files").
 3. Open the repository's "Actions" tab, choose "Build APK", click "Run workflow".
 4. After about 4 minutes open the finished run, download "DiagnoSphereX-apk" under Artifacts,
    unzip it, and you have app-debug.apk. Send it to your phone and install it.

OPTION B - on your own laptop
 Needs Node.js 18+, JDK 17, Android Studio (for the SDK).
   npm install
   npm run setup
   npm run build
 APK: android/app/build/outputs/apk/debug/app-debug.apk
